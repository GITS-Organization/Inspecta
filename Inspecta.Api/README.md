# Inspecta API

This project contains only the ASP.NET Core backend. Setup, deployment, Swagger, and endpoint documentation are maintained in the repository [README](../README.md).

Run it from the repository root with:

```powershell
dotnet run --project .\Inspecta.Api\Inspecta.Api.csproj
```

When running locally, Swagger UI is available at `http://localhost:5238/swagger`. API request examples for every endpoint are in [Inspecta.Api.http](./Inspecta.Api.http).
